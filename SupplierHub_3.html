⚡ Bulk Import — Nhập hàng loạt NCC

Cách dùng:
  1. Vào tab 📝 Lấy Prompt mẫu → copy prompt
  2. Mở Claude/ChatGPT → paste prompt + upload file contract của NCC
  3. AI trả về JSON → copy toàn bộ JSON
  4. Paste vào ô bên dưới → bấm Preview → kiểm tra → Import

Hỗ trợ 1 NCC (object {}) hoặc nhiều NCC (array []).

Cách dùng:
  1. Mở Excel/Google Sheets với danh sách NCC của bạn
  2. Đảm bảo có các cột bắt buộc: category, name, region
  3. Cột tùy chọn: contactName, phone, email, vat, paymentDays, mst, rating, notes
  4. Chọn toàn bộ vùng (gồm cả header) → Ctrl+C → paste vào ô dưới

Lưu ý: Giá trị category phải là: hotel, cruise, xe, land, nh, tq, hdv, bh

Quy trình AI Extract (30 giây/file):
  1. Chọn loại NCC ở dưới → bấm Copy Prompt
  2. Mở Claude hoặc ChatGPT
  3. Paste prompt + đính kèm file contract PDF/Word của NCC
  4. AI trả về JSON → copy → quay lại tab 🤖 Paste JSON
